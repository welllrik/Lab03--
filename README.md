# Lab03--
1. Результат тот же, просто запись короче и удобнее для чтения.
2. Постфикс x++ возвращает старое значение и потом увеличивает переменную. Префикс ++x — сначала увеличивает, потом возвращает новое.
3. Всегда логический тип bool — true или false.
4. Короткое замыкание — когда C# не проверяет остальные условия, потому что итог уже известен: в && после false первое условие дальше не идёт, в || после true — тоже. Пример: b != 0 && a / b > 2 — при нуле в b деление не выполнится и ошибки не будет.
5. Сначала умножение и деление (2 × 3 = 6, 4 / 2 = 2), затем слева направо: 10 − 6 + 2 = 6.
6. Код читают люди: без скобок нужно держать в голове таблицу приоритетов, а со скобками порядок виден сразу — и меньше шансов ошибиться.
